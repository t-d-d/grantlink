# Licence
Relevance: LICENSE, the README's licence and credit, package.json's licence, or anything the repo or the page republishes from a paper
Decision: The code is under Apache 2.0, which covers the code only. Titles and funding text belong to their publishers, and Europe PMC is credited.

Why: The repo and the page are public. Papers in Europe PMC's open-access
subset are still under copyright, each under its own licence, so the
code's licence must not seem to cover them. Europe PMC's terms ask for a
credit.

## Rules

- `LICENSE` is the Apache License 2.0, and `package.json` says
  `Apache-2.0`.
- The README says that paper titles and funding text belong to their
  publishers, under each paper's own licence.
- The README and every view of the page credit Europe PMC, with a link to
  it and to EMBL-EBI's terms of use.

## Do not

- Put a licence notice on the data. grantlink does not own it and cannot
  license it.

## Judgment

What the page may show from a paper, titles, links and grant references
only, lands with the page's results in #19.

grantlink

Grant links that papers state but Europe PMC does not hold

grantlink is an independent demonstration on public data from Europe PMC. It is not affiliated with or endorsed by Cancer Research UK.

Europe PMC links a paper to a grant only when the grant number is in the paper's structured metadata. Many papers that thank Cancer Research UK for funding give the grant reference only in their text, so Europe PMC links them to no grant.

grantlink reads the funding text of those papers, finds the grant reference, and checks it against the links Europe PMC already holds. It tries rules first, then a model. It accepts only what clears thresholds set by its evaluation, and sends everything else to a person for review.

Beside the links, this page will show how the service is run: the go/no-go criteria set before the build, the evaluation that gates every release, and the check behind every limit it works within.
